A per-action defense for tool-using LLM agents

The problem

The request the defense sees is a sliding window.

An attack planted 20 steps ago is outside it —
which is exactly where memory poisoning hides.

The approach

A provenance graph that persists per run,
so distrust survives outside the window.

Five signals — trust, taint, divergence, sensitivity,
reversibility — fused into one calibrated risk score.

Honest limits

  • The kit's provenance baseline scores 0.988302 — ours 0.988437. One ten-thousandth apart.
  • Redaction is regex-based: reversed, spaced or split secrets are not caught by that pattern.
  • All runs shown use --model mock, which is more credulous than Qwen3-8B.

What it does not claim

Not complete security.

A defense that constrains what an agent may do
with untrusted content — without refusing to read it.
